## Overview

**Dosh** wasn't built to compete with the giants of the text-editing world. It's meant to be a surgical tool: lightweight enough to run anywhere, yet thoughtfully equipped with the small tweaks and features you often find yourself missing in traditional editors.

Built with **Go (Golang)**, it prioritizes portability, low resource consumption, and a straightforward learning curve.
